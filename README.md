This project is my personal portfolio page. It introduces who I am, highlights my core skills, and gives visitors a clear way to get in touch. The goal was to build a clean, readable layout from scratch using only HTML and CSS, with no frameworks or libraries.

# Features
Hero section with a bold introduction\
About me section with a profile photo and short bio\
Skills section showcasing what I do:\
Design and Development\
Building and Debugging\
Contact section with a call-to-action button\
Footer with links to social profiles (LinkedIn, Twitter, WhatsApp)\
Responsive layout that adapts to different screen sizes\
# Built With
HTML5: semantic page structure
CSS3: styling, layout, and responsiveness
